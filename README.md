# SwiftCart E-Commerce

- **Live Site:** https://swiftcart-rajib.netlify.app
- **GitHub Repository:** https://github.com/rajib-hossen-360/swiftcart-e-commerce

## Features
- Dynamic product fetching from FakeStore API
- Category filtering
- Detailed product view in modal
- Interactive shopping cart
- Fully responsive design using Tailwind CSS & DaisyUI
